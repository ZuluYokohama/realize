# Papers

`realize` re-implements the finite kernel of these manuscripts. PDFs are not vendored here.

- **IGVF–CTS** — intent specification, representation adequacy, typed term series. Grid recoloring example (§7.1).
- **Value-Conditioned Operator Synthesis (VCOS)** — `Realize_M`, four verdicts, Table 2 formula template, four-bit encoding, guarded series, JSON exchange, §9.4 priorities.
- **Value-Conditioned Meta-Operations / VCMS Extensions** — fibre-intersection criterion, obstruction-guided hitting set, three-state example.

The public object of this repository is the independent checker, not the geometric or topological specializations discussed in those papers.
