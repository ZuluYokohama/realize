# Papers

`realize` re-implements the **finite evidence kernel** of this architecture. PDFs are not vendored here.

The theory of record for this repository:

- [architecture.md](architecture.md) — layer map from *Formalizing Intent into Substance* onto what this package actually checks.
- [relational-section.md](relational-section.md) — certificate pattern for relational / dressing programs: no privileged viewpoint, no privileged proposer. Lattice DFM adapter is not shipped.

Source manuscripts (session PDFs, not in git):

- **IGVF–CTS** — intent specification, representation adequacy, typed term series. Grid recoloring example.
- **Value-Conditioned Operator Synthesis (VCOS)** — `Realize_M`, four verdicts, Table 2 formula template, four-bit encoding, guarded series, JSON exchange.
- **Value-Conditioned Meta-Operations / VCMS Extensions** — fibre-intersection criterion, obstruction-guided hitting set, three-state example.

The public object of this repository is the independent checker: hard constraints, fibres, typed terms, four verdicts, preference cannot rewrite evidence.

Not in this package: conformal value metrics, persistent homology, knowledge-graph `Φ`, schematism, SMT proposers, ASTAC telemetry, geometric LNNs, Dressing Field Method, holonomy. See [NONCLAIMS.md](../NONCLAIMS.md).
